# Usinagem Alecrim — Site institucional

Site institucional responsivo desenvolvido em HTML, CSS e JavaScript puro.

## Estrutura

- `index.html`: conteúdo e estrutura do site.
- `css/style.css`: identidade visual, layout e responsividade.
- `js/script.js`: menu mobile e ano automático do rodapé.
- `assets/`: diretório reservado para logo e imagens próprias.

## Executar localmente

Abra o arquivo `index.html` no navegador. Para desenvolvimento, recomenda-se usar a extensão Live Server do Visual Studio Code.

## Publicar no GitHub Pages

1. Crie um repositório público chamado `usinagem-alecrim`.
2. Envie todos os arquivos e pastas deste projeto para a raiz do repositório.
3. No GitHub, acesse **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch `main` e a pasta `/ (root)`, depois salve.
6. Aguarde a publicação. O GitHub exibirá o endereço público do site na mesma tela.
